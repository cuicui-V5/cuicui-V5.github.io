## 痛点：为什么小米蓝牙遥控器 2 Pro 在 Windows 上这么难用？

**小米电视蓝牙语音遥控器 2 Pro（型号：RC003）** 拥有极高质感的铝合金磨砂外壳、清脆的微动按键，还有专属的语音按键，是很多朋友用来做 PC 沙发多媒体控制、PPT 演示翻页、或者无线语音打字的神器。

但只要你试过直接用电脑蓝牙连接它，就会发现两大**致命痛点**：

1. **按键失效（音量+、音量-、返回键完全没反应）**：  
   遥控器的「音量+ (0x80)」、「音量- (0x81)」和「返回 (0xF1)」三个键采用了非标 HID 编码。Windows 自带的 `kbdhid.sys` 蓝牙键盘驱动会在内核层直接丢弃它们，导致所有上层软件（包括全局钩子、RawInput、AutoHotkey）根本收不到按键事件。要想救回这三个键，纯软件方案必须装内核驱动并开启系统“测试签名”，不仅有蓝屏风险，更会被各大游戏反作弊程序（如腾讯 ACE、拳头 Vanguard 等）拦截封号。
2. **语音键无法当普通麦克风使用**：  
   遥控器语音走的是私有 ATVV 协议。纯软件方案必须在后台常驻进程，并借助第三方虚拟声卡（如 VB-Cable）转接二次路由，配置极其繁琐、偶发无声且延迟高。

为此，我开发了 **[RemoteMapper-ESP32](https://github.com/cuicui-V5/RemoteMapper-ESP32)** 硬件桥接方案：利用一块小巧便宜的 **ESP32-S3** 开发板充当“硬件翻译官”，彻底解决上述所有问题！

## 核心特性：它能为你带来什么？

* 🎯 **13 个物理按键全功能无损复活**：上游 BLE 直接抓取空口原始报文，彻底绕过 Windows 内核过滤，被丢弃的音量加减和返回键完美工作！
* 🎙️ **原生免驱 USB 物理麦克风（UAC 1.0）**：电脑直接识别为标准免驱硬件麦克风（`RemoteMapper Mic`）。按住语音键即可呼出微信输入法/讯飞输入法无线流式打字，无需任何虚拟声卡软件，无额外系统延迟。
* 🎧 **内置专业音频优化**：按下语音键瞬间自动注入输入法语音热键（默认 `Alt + ,`），前置 150ms 硬件静音滤除微动物理咔哒杂音，配合 10ms 微淡入与 AGC 软启动，彻底告别爆音与杂音。
* 🔀 **强大的 5 层按键映射与防呆系统**：
  * 支持**单击**、**长按**（200~2000ms 可调）、**双击**（100~600ms 可调）；
  * 提供 5 个独立映射层（默认层 + 层 1~4），支持永久层、单次触发层与超时自动返回层；
  * 自动穿透继承与防呆反转，并支持按层定义板载 RGB 指示灯颜色。
* ⚡ **局域网网络唤醒 (Wake-on-LAN / WOL)**：支持把任意按键（如长按电源键）绑定为广播 WOL 魔术包，躺在床上按一下遥控器即可开机或唤醒休眠中的电脑。
* 🌐 **内置 Web 可视化配置后台**：ESP32 自带 Web 服务器，用手机或电脑浏览器即可完成遥控器配对、可视化按键拖拽映射，配置保存于 NVS Flash，掉电不丢。
* 🔋 **遥控器电量监控与低电量报警**：Web 界面实时显示电量百分比；当电量 ≤ 15% 时，ESP32 板载 RGB 自动双闪白光，提醒更换遥控器电池。
* 🛡️ **安全即插即用，零后台常驻**：电脑端视其为标准免驱 USB 设备，无需开测试签名，不占电脑 CPU/内存，对所有游戏反作弊完全透明。

## 快速上手教程（5 分钟搞定）

项目支持 **ESP32-S3 N16R8 / N8R2 / N4R2** 等主流规格。无需安装 Python、Git 或任何开发编译环境，新手开箱即用！

### 步骤 1：硬件准备与接线
1. 准备一台 **小米蓝牙语音遥控器 2 Pro（型号：RC003）**；
2. 准备一块 **ESP32-S3 开发板**；
3. 用具备数据传输能力的 Type-C 数据线，将 ESP32-S3 的 **`USB`（或 `OTG`）接口** 连接至电脑。（*注意：双口开发板切勿插在 UART 接口上*）。

### 步骤 2：零环境一键刷机
1. 前往 GitHub 仓库 [Releases](https://github.com/cuicui-V5/RemoteMapper-ESP32/releases) 下载最新版的刷机工具包（`RemoteMapper-Flasher`）并解压；
2. 按住开发板上的 **`BOOT`** 键不放，点按一下 **`RST`** 重启键，松开 **`BOOT`** 键进入烧录模式；
3. 双击运行解压目录下的 **`一键烧录.bat`**，根据全中文向导选择对应的开发板规格与 COM 端口，几十秒内全自动写入固件。

### 步骤 3：网络配置与蓝牙配对
1. 首次通电后，ESP32 会发射名为 **`RemoteMapper-AP`** 的热点（无密码），手机或电脑连接后在浏览器打开 `http://192.168.4.1/`；
2. 在「Wi-Fi 与系统配置」中连接家庭路由器 Wi-Fi（之后可在局域网通过分配的 IP 直接访问后台）；
3. 切换到「蓝牙配对管理」页面，拿起遥控器，**同时长按「主页键」与「菜单键」3 秒**，待指示灯快闪后在网页点击「扫描蓝牙设备」并连接绑定（配置永久保存，后续开机秒连）。

### 步骤 4：畅享输入法语音打字
1. 在 Windows 声音设置或微信输入法/讯飞输入法设置中，将音频输入源切换为：**`RemoteMapper Mic`**；
2. 确认输入法开启了语音输入（微信输入法默认热键为 `Alt + ,`）；
3. 拿起遥控器，按住语音键说话，松手即完成输入！

## 深入技术探究（写给极客朋友们）

对于喜欢探究底层技术的朋友，这里简单介绍一下软硬件实现架构与踩坑经验：

### 1. 架构拓扑
```text
┌────────────────────────┐      BLE 5.0 (HOGP + ATVV)      ┌────────────────────────┐
│                        │ ──────────────────────────────► │                        │
│   小米蓝牙遥控器 2 Pro │                                 │     ESP32-S3           │
│   (RC003)              │ ◄────────────────────────────── │   (Central 主机)       │
└────────────────────────┘                                 └───────────┬────────────┘
                                                                       │ USB 2.0 Full-Speed
                                                                       │ (原生 USB OTG 复合设备)
                                                                       ▼
                                                           ┌────────────────────────┐
                                                           │   PC 宿主机 (Windows)  │
                                                           │ • 标准 UAC 1.0 麦克风  │
                                                           │ • 标准 USB HID 键盘    │
                                                           │ • 标准 Consumer 媒体键 │
                                                           └────────────────────────┘
```
ESP32-S3 一端充当 BLE Central 主机抓取私有 HOGP/ATVV 报文，另一端通过硬件原生 USB 控制器模拟标准的复合免驱输入设备，让 Windows 从物理层直接接收标准按键与 PCM 音频流。

### 2. 开发中的三大经典排错
* **TinyUSB UAC 麦克风 500Hz 降频与锯齿电流音**：ESP32-S3 的 DWC2 USB 控制器在没有开启 SOF 中断时，FreeRTOS 调度的微小延迟极易跨越 1ms 微帧边界，导致端点奇偶帧判定错位降频至 500Hz。通过重构等时传输时序排队彻底解决了杂音问题。
* **ATVV 语音长按 3 秒必断**：小米遥控器工作在 HTT (Hold-To-Talk) 模式下，代码如果误按 PTT 逻辑下发 `AUDIO_EXTEND (0x0E)` 保活包，会导致遥控器内部状态机崩溃断开。去掉该保活包后，恢复无限长录音。
* **极速连按下的 Ghost Key 粘键**：遥控器在按键迅速交替时可能丢失抬起包，驱动层通过实现互斥自动释放（Auto-Release）机制，彻底杜绝了按键卡死问题。
