最近改论文的时候, 经常需要给特定的内容添加引号. vscode 等编辑器使用多了就很希望 word 也能有给选中内容快速添加引号的功能

这个需求我们可以使用宏快速实现

## 步骤

1. 点击 `视图` => `宏` => `创建`
2. 在编辑器中输入以下内容

    ```vb

    Sub AddQuotes()

        Dim sBegQ As String
        Dim sEndQ As String

        sBegQ = "“"
        sEndQ = "”"

        Selection.InsertBefore sBegQ
        Selection.InsertAfter sEndQ
    End Sub

    ```

3. 在`文件` => `选项` => `自定义工作区` => `键盘快捷方式-自定义` 中 , `类别`选择`宏`, `宏`选择刚刚添加的`宏`,然后在`请按新快捷键`中绑定一个快捷键, 点击指定快捷键后关闭页面即可。![2023-04-29T212823](/images/posts/2023-04-29-word-快速给选中内容添加引号/2023-04-29T212823.png)
4. 然后即可选中文字按快捷键插入引号了.🎉🎉🎉
